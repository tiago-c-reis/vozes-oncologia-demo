# Vídeo de apresentação — Vozes da Oncologia

Esta pasta destina-se aos ficheiros estáticos do vídeo de apresentação na homepage.

## Ficheiros a carregar nesta pasta

- `vozes-oncologia.mp4` — vídeo otimizado em H.264/AAC, 1280 × 720, cerca de 9,1 MB.
- `vozes-oncologia-poster.jpg` — fotograma de apresentação (capa), 1280 × 720.

**Antes de fazer merge do pull request**, carregar ambos os ficheiros nesta pasta **na branch `feature/video-explicativo-home-20261111`** através de **Add file → Upload files** no GitHub. Não carregar o original 4K de 147 MB.

A homepage contém um leitor HTML5 com reprodução por clique, controlos nativos, modo ecrã completo e layout responsivo. Sem reprodução automática e sem serviços externos de rastreio.

Depois de carregar os dois ficheiros, testar o vídeo num navegador de computador e num telemóvel. Só depois fazer merge para `main`.
